# Caesar Cipher

This project is a simple Caesar Cipher program written in Python. It can encrypt and decrypt messages by shifting letters based on a number provided by the user.

### Features

* Encrypt text
* Decrypt text
* Choose any shift value
* Spaces, numbers, and symbols stay unchanged

### How to Run

Run the program using:

```bash
python caesar_cipher.py
```

Then enter your message and the shift value, and choose whether you want to encrypt or decrypt it.

### Example

```text
Message: Hello World
Shift: 3
Encrypted: Khoor Zruog
```

### Language

Python 3
